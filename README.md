# GIS Portfolio: Samayak Chakma

Personal GIS portfolio site, hosted with GitHub Pages.

## Files

```
index.html      Page content (bio + 5 projects)
style.css       Styling
images/         Profile photo and map preview images
maps/           Full-resolution map PDFs
```

## Publish on GitHub Pages

1. Upload all of these files to the root of the `gis-portfolio` repository (keep the `images` and `maps` folders).
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. After a minute or two the site is live at `https://samayakchakma.github.io/gis-portfolio/`.

## Updating

- **Photo:** replace `images/profile.jpg` with your own photo, keeping the same file name. A square photo works best.
- **Project 5:** in `index.html`, fill in the bracketed `[ ]` text. Then add your map image to `images/` and its PDF to `maps/`, and swap the placeholder block for the commented-out `<img>` code.
- **Project 4 image:** add a screenshot of the 3D model or dashboard as `images/drillhole-model.jpg`, then use the commented-out code in Project 4.
- **New map images:** export at about 150 dpi as JPG to keep the page fast.
